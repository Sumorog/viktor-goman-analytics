# 04 — ТЗ: интеграция носимых устройств с ЕМИАС

**ТЗ согласовано с 5 клиниками ДЗМ**; версия 1.3 закрывает замечания UAT. Конечная цель — **интеграция в промышленную эксплуатацию** на пилотном контуре с последующим масштабированием на регионы РФ и СНГ при сохранении контрактов API и форматов JSON.

## Главный документ

- **[tz_emias_integration.md](tz_emias_integration.md)** — цели, архитектура REST/JSON, ошибки, безопасность, критерии приёмки, промэксплуатация.

## Связанные материалы (один контур согласования)

| Файл | Роль |
|------|------|
| `Коды.csv` | Справочник кодов услуг/событий для обмена |
| `Приёмка.txt` | Чек-лист приёмки пилота |
| `Требования к безопасности.txt` | Требования ИБ и ПДн |
| `Открытые вопросы (на момент ТЗ).txt` | Вопросы к заказчику/ЕМИАС |
| `Ответ ЕМИАС.json` | Пример ответа шины (обезличено) |

Конфигурация ИИ-сервиса рядом с этим кейсом — в [05-json-configs](../05-json-configs/).
