# Словарь таблиц (тарифный контур ОЭЗ, обезличено)

Ниже — логические имена, как в примерах SQL. В реальной инсталляции префиксы схем и физические имена отличались.

| Таблица | Назначение | Ключи для JOIN |
|---------|------------|----------------|
| `contracts` | Договор резидента с ОЭЗ | `contract_id`, `resident_id`, даты действия |
| `residents` | Карточка резидента (сегмент: крупный / средний / малый) | `resident_id` |
| `service_volumes` | Факт объёмов по услугам за период | `contract_id`, `service_code`, `period_month` |
| `tariff_rates` | Версии тарифов по услуге и датам | `service_code`, `rate_from`, `rate_to` |
| `accruals_fact` | Проведённые начисления (после закрытия месяца) | `contract_id`, `period_month`, `amount` |
| `accruals_1c_staging` | Стейджинг выгрузки из 1С для сверки | `external_doc_id`, `amount`, `service_code` |

**Зачем столько JOIN:** тариф зависит от периода и кода услуги; объёмы живут в операционном слое; сегмент резидента нужен для аналитической разбивки выручки; сверка с 1С — по бизнес-ключу документа и сумме.
