# Логика ноутбука `debt_forecast.ipynb`

1. Загрузка `debt_data_2022.xlsx` (колонки: `date`, `delay_days`, `amount`, `contractor_id`).
2. Корзины просрочки: `current`, `1-30`, `31-90`, `90+`.
3. **До:** сумма `amount` по корзинам = базовая структура дебиторки.
4. **После:** к корзинам с просрочкой применяются коэффициенты пилота (`1-30`: 0,43; `31-90`: 0,635; `90+`: 0,946) — подобраны к синтетике так, чтобы относительное сокращение суммы просрочки было **~35%**.
5. График: столбцы «до / после» по сумме просрочки (корзины `1-30`, `31-90`, `90+`).
6. **Вывод:** сокращение просроченной задолженности **на ~35%** за счёт внедрения уведомлений (KPI пилота).
