# 06 — Анализ дебиторской задолженности

Ноутбук: загрузка обезличенной выгрузки, сегментация по сроку просрочки, простой сценарный прогноз эффекта от автоматизации напоминаний.

## Файлы

- `debt_forecast.ipynb` — расчёты и текст на русском.
- `debt_data_2022.xlsx` — синтетические данные для воспроизводимости (не реальные контрагенты).

## Запуск

```bash
pip install pandas openpyxl numpy matplotlib
jupyter notebook debt_forecast.ipynb
```
