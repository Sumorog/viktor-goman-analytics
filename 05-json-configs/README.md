# 05 — JSON-конфиги для ИИ-моделей

Пример структурированной настройки: модель, параметры генерации, лимиты токенов, политика fallback.

## Файлы

- `model_config.json` — один файл-образец для сервиса, который читает конфиг при старте.

## Использование

На проде конфиги лучше хранить в секрет-менеджере и версионировать отдельно от кода; здесь — учебный минимум.
