# 09 — Unit-экономика

Excel-файл с листами: допущения, расчёт выручки на единицу, переменные и постоянные расходы, маржа, окупаемость CAC.

## Файлы

- `unit_calc.xlsx` — формулы на ячейках (цифры вымышленные).

## Как читать

Лист «Summary» агрегирует показатели; лист «Inputs» — редактируемые параметры для сценариев.
