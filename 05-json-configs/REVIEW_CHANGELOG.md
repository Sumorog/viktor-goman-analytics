# Журнал ревью конфига (v1 → v2.1)

Обобщённый список категорий замечаний (**20+** пунктов в трекере, здесь — группы):

1. **Лимиты и стоимость:** `max_output_tokens`, отдельный лимит на стриминг, cap на суточный расход.
2. **Fallback:** явная цепочка моделей при деградации провайдера; запрет «тихого» переключения без логирования.
3. **ПДн:** маскирование телефонов/Email в промпте; запрет `json_mode` для чувствительных сценариев.
4. **Наблюдаемость:** обязательный `request_id`, корреляция с шлюзом ЕМИАС.
5. **Локаль и формат:** `default_locale`, часовой пояс, формат дат ISO-8601.
6. **Retry:** политика повторов только для идемпотентных вызовов.

Версия **v2.1** — минор после v2.0 (правка таймаутов WebSocket).
