# Участие в репозитории

Это **личное портфолио**, не open-source продукт с внешними контрибьюторами. PR и issue по мелким опечаткам приветствуются; крупные изменения — по согласованию с автором.

## Как предложить правку

1. Fork → ветка → понятный коммит-месседж на русском или английском.  
2. Не добавлять персональные данные, внутренние URL организаций и закрытые договоры.  
3. Сохранять стиль: обезличенные примеры, явные пометки «демо / учебный кейс».
