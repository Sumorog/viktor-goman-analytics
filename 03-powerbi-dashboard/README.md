# 03 — Дашборд Power BI

Материалы к дашборду мониторинга выручки и загрузки: связь фактов со справочниками, меры на DAX (в живом проекте — внутри PBIX).

## Файлы

- `dashboard_screenshot.png` — заглушка-скрин (вместо реального снимка экрана с чувствительными цифрами).
- `data_model.png` — схема звезда/снежинка на уровне концепта.

## Что обычно внутри модели

- Таблица фактов продаж/оказания услуг по дням.
- Календарь, справочники контрагентов, SKU, каналов.
- Меры: выручка, план/факт, маржа, скользящие средние.
