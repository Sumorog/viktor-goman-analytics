# 02 — Автоматизация расчётов (Python)

Скрипт читает выгрузку из Excel (типичная цепочка «1С → файл → проверка → результат»), считает суммы по справочнику тарифов и сохраняет отчёт.

## Запуск

```bash
pip install pandas openpyxl numpy
python auto_calc.py --input input_data.xlsx --output result.xlsx
```

## Файлы

- `auto_calc.py` — расчёт по строкам и сводка по видам услуг.
- `input_data.xlsx` — демонстрационные строки (вымышленные контракты и объёмы).
