# 01 — SQL: тарифы и расчёты

Пример расчёта начислений по договорам и справочнику тарифов: объединения таблиц, фильтры по периоду, агрегация.

## Файлы

- `tariff_calculation.sql` — основной запрос (PostgreSQL-совместимый синтаксис, комментарии на русском).
- `schema.png` — упрощённая схема связей таблиц (заглушка до финальной диаграммы).

## Статус

Рабочий пример для портфолио; названия сущностей обобщены.
