# 03 — Дашборд Power BI

Материалы к дашборду: **живой скриншот** (`dashboard_screenshot.png`) и схема модели (`data_model.png`) сгенерированы скриптом `../scripts/render_portfolio_assets.py` (matplotlib как **макет** визуала Power BI).

## Источник данных для учебного скрина

Портал открытых данных Москвы ([data.mos.ru](https://data.mos.ru)) для **продакшена** требует API-ключ. Здесь используется файл **[sample_mos_open_style.json](sample_mos_open_style.json)** — демо-структура «округ → показатели», по которой строятся метрики на PNG. Чтобы подключить **живой** API, задайте `MOS_DATA_API_KEY` и замените загрузку в скрипте на вызов `https://apidata.mos.ru/v1/datasets/{id}/rows`.

## Что на скриншоте (метрики)

| Панель | Метрика | Смысл |
|--------|---------|--------|
| Верх слева | Обращения по округам (шт.) | Горизонтальная столбчатая — сравнение территорий |
| Верх справа | Удовлетворённость (1–5) | Линейный тренд по округам (демо) |
| Низ | Накопительный итог обращений | Кумулятив для оценки «веса» территорий в потоке |

Связь с SQL-витринами тарифов: меры в [dax_measures.txt](dax_measures.txt) стилистически согласованы с логикой [01-sql-tariffs](../01-sql-tariffs/).
