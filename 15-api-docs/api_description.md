# API биллинга (пример описания)

Базовый URL: `https://api.example-billing.ru/v1`  
Аутентификация: заголовок `Authorization: Bearer <token>`

## Ресурсы

### GET /contracts/{id}

Возвращает карточку договора.

**Ответ 200**

```json
{
  "id": "C-10001",
  "status": "active",
  "valid_from": "2023-01-01",
  "counterparty": {
    "name": "ООО Ромашка",
    "inn": "7700000000"
  }
}
```

### POST /accruals/preview

Расчёт начислений без проводок (черновик).

**Тело запроса**

```json
{
  "contract_id": "C-10001",
  "period": "2024-05",
  "services": [
    {"code": "HEAT", "qty": 120.5},
    {"code": "RENT", "area_sqm": 85.0}
  ]
}
```

**Ответ 200** — массив строк начислений с суммами и НДС.

## Коды ошибок

| Код | Значение |
|-----|----------|
| 400 | Неверные параметры |
| 401 | Нет или просрочен токен |
| 404 | Договор не найден |
| 409 | Конфликт версии договора |
| 429 | Превышен лимит запросов |

## Версионирование

Префикс `/v1` сохраняется при обратно совместимых изменениях; ломающие изменения — новая мажорная версия.
