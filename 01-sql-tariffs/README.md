# 01 — SQL: тарифы ОЭЗ «Технополис»

**Рабочие запросы из системы тарифного планирования ОЭЗ** (обезличенные имена резидентов и договоров). Контур биллинга обслуживал портфель с совокупной выручкой порядка **5,5 млрд руб.** — здесь воспроизведена логика расчётов и сверок без коммерчески чувствительных реквизитов.

## Связь файлов в папке

| Файл | Назначение |
|------|------------|
| [tariff_calculation.sql](tariff_calculation.sql) | Начисления по договору × справочник тарифов за квартал |
| [query_revenue_by_resident_segment.sql](query_revenue_by_resident_segment.sql) | Выручка по сегментам резидентов и видам услуг (для отчёта руководству) |
| [query_accruals_reconciliation.sql](query_accruals_reconciliation.sql) | Сверка факта начислений с регистром 1С (контрольные суммы) |
| [oas_table_glossary.md](oas_table_glossary.md) | Словарь таблиц и полей — к чему относятся JOIN в запросах |
| `schema.png` | Упрощённая схема связей (заглушка-напоминание структуры) |

## Стек

PostgreSQL / совместимый диалект; в проде часть логики дублировалась в **1С** и **Excel**-надстройках — SQL оставался «источником правды» для тяжёлых выборок.
